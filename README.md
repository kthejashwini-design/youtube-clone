# YouTube-Inspired Frontend Webpage

## 📌 About the Project

This project is a *YouTube-inspired frontend webpage* created from scratch using *HTML and CSS*. The main goal of this project was to practice and improve my understanding of frontend web development by recreating the basic layout and visual structure of a popular video-sharing platform.

The webpage focuses on creating a clean and organized user interface similar to YouTube, including a navigation bar, search bar, video thumbnails, channel profile images, video information, and different sections of the webpage.

## 🎯 Project Objective

The objective of this project was to gain practical experience with *HTML and CSS* by designing a real-world inspired webpage. Instead of only learning individual HTML tags and CSS properties, I applied them together to create a complete webpage layout.

Through this project, I practiced:

* Structuring a webpage using HTML
* Styling elements using CSS
* Creating navigation bars and search sections
* Working with images and video thumbnails
* Creating grid-based layouts
* Positioning and aligning different elements
* Using CSS properties such as margins, padding, borders, colors, and font styles
* Creating buttons and interactive-looking UI elements
* Organizing project files and assets

## 🛠️ Technologies Used

* *HTML5* – Used to create the structure and content of the webpage.
* *CSS3* – Used for styling, layout, positioning, colors, fonts, and overall appearance.

## ✨ Features

* YouTube-inspired navigation bar
* Search bar and search button
* Video thumbnail grid
* Channel/profile images
* Video titles and channel information
* Video views and upload information
* Structured webpage layout
* Styled buttons and UI elements
* Organized image assets
